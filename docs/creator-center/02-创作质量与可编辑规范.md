## 2. 上线质量与优质质量是两层标准

**平台要求**（[S01](sources/fr75o0cutbee4r54.txt)）：上线须同时满足法规和平台基础标准、编辑可用、版权合规可商用、真实场景、内容上线质量。优质还须符合上线标准、综合质量达到平台优质水平，有明确应用场景且匹配需求、原创度更高、与平台内容不雷同，并在画面和文案上创意出新。原文强调“非纯画面好看”，没有公开综合评分公式或数值分数线。

基础底线包括：不得搬运、抄袭、复制；不得提交未经实质修改的稿定模板；避免重复投稿，多个重复作品视为同一作品；不可出现知名 IP（原文包括人物、动漫等）。法规条目还列出国家象征、政治敏感、暴力色情、歧视、迷信赌博、违禁内容和恶意引流等禁止内容。该摘要不能代替平台完整禁止清单。

版权要求是授权明确、素材和字体可追溯，来源为稿定素材或原创素材；来源不明、含未授权非官方内容、疑似侵权、命中商标/IP/字体黑库或有效投诉均有风险。**“AI生成”“已经换风格”“在编辑器里能用”不能由本文推导为自动获得商用授权。**

## 3. 美观度、排版与配色：应检查什么

以下是[质量标准 S01](sources/fr75o0cutbee4r54.txt)的文字维度归纳，并非从图片观察所得。

| 平台维度 | 平台文字要求 | 工程建议：具体检查办法 |
| --- | --- | --- |
| 画质清晰 | 所有元素清晰无压缩，无明显锯齿、低画质模糊 | 在实际使用尺寸与局部放大时检查边缘、文字、抠图；同时看最终导出与编辑器呈现 |
| 信息准确完整 | 成品而非半成品；无错别字、语句不通顺、信息错漏；清晰易懂 | 按真实用途逐一校对主题、对象、时间地点、权益条件、行动入口；不要把占位内容当成完整成品 |
| 风格统一 | 元素与背景一致；字体与整体协调；贴合平台当下审美 | 检查写实/插画、材质、光影与字形是否协调；不能仅凭单个素材精致判整稿合格 |
| 元素精准 | 元素匹配主题，无明显造型或材质错误 | 检查图文语义、产品结构、人物与物件细节；AI 素材同样检查 |
| 版式合理 | 对齐有序，对比合理，构图平衡 | 先明确主标题、核心信息、辅助信息的阅读顺序，再检查对齐、留白与视觉重心 |
| 配色协调 | 色彩不杂乱；主视觉和文字与背景有明显色彩对比，易识别 | 检查文字所在局部背景的识读性；不能只看整图主色是否和谐 |
| 平台审美 | 与平台调性一致，关注主流趋势，避免过时老旧 | 制作时研究当前同类内容；这里没有固定色数、字体数、对比度数值或统一布局公式 |
| 避免雷同 | 与站内模板充分差异化；过于相似直接判低质量 | 对比文案、排版、元素、构图及用途是否共同发生有价值变化；保留比较依据 |

**注意**：原文建议通过稿定搜索关键词并查看“最新上传”了解审美趋势；这是一种研究入口，不意味着最新上传的每个作品都已被认定为优质。本文未执行当前站内研究。

## 4. 真实使用场景先于视觉装饰

**平台要求**（[S01](sources/fr75o0cutbee4r54.txt)）：作品基于实际生活或工作应用，不能虚构或仅为投稿而作；用途与受众明确；提倡自有摄影、手绘、AI 等素材体现特色；鼓励文案与创意包含生活洞察。

[节日页 S10](sources/as18mhfepahawprs.txt)给出的前置问题最适合转成创作需求：给哪个行业、面向什么人群/渠道、在什么场景、宣传什么用途。节日模板不能仅依赖“节日快乐”；可转成具体出游、避雷指南、放假通知、福利领取流程等。平台文字反对地点笼统、AI 素材感强、无实景证明、推荐语生硬，鼓励具体目的地与行为、第一人称体验感，以及明确福利和操作。

**工程建议**：每稿先填写“行业—受众—渠道—用途—核心信息—可替换内容”。“真实感”是表达质量要求，不能据此伪造本人体验、实景摄影或品牌活动事实。

## 5. 分层、文本、字体与 PSD

### 5.1 分层的目的：让用户改字、换图后即可使用

**平台要求**（[S05](sources/nq8p150hfxrzpoi5.txt)，并见[原创 S02](sources/cnnzufvbv3wq9a9n.txt)、[二创 S03](sources/ar4fq2gbqxcz5ivn.txt)）：

1. 人物、产品与背景彻底拆分。挪开所有主体/前景后，背景应干净，无多余元素。
2. 凡可独立使用的主视觉/前景元素都应是完整独立图层，原文举人物、产品、菜品、花朵、奖杯、船、帐篷等。AI 生图也应拆分。
3. 可移动元素本身完整无残缺，保证单独替换、移动、删除。
4. 元素与投影合理分层并成组；优先用编辑器特效还原投影，无法还原时拆出投影层。
5. 相邻或整体性强的元素成组，如主副标题和装饰色块、小标题和正文、产品和投影。
6. 超出画布过多的无效部分可适当裁减，以利打开顺畅；此项不应被解释成可以破坏主物件完整性。

**工程建议**：隐藏主体与前景检查背景，再单独移动/替换主体，检查独立素材边缘与完整性；恢复后确认合成效果。按语义验收，不用图层数量或 PSD 文件存在代替可编辑判断。背景、产品、文字、装饰拆分是原文要求；“每个日期或价格必须独立一个文本框”等更细颗粒规则并未在本组资料中统一规定。

### 5.2 文字可编辑与适度精简

**平台要求**（[S05](sources/nq8p150hfxrzpoi5.txt)）：文字保持文本状态，双击可编辑；以双击后出现文字调整页面作为判断方法。商品主图所有文字需可编辑，海报示例特别写到包括“YOUR LOGO”。基础特效如渐变、描边、投影、划重点、变形需可还原。同类型、相邻字号、可通过变形等特效还原的文字尽量同一文本框，避免无意义碎片化。

**明确例外与冲突**：该页同时保留“特殊非必要改动字体，如劳动节、喜报等有专项用途的主标题”的非文本例外；[S01](sources/fr75o0cutbee4r54.txt)、[S02](sources/cnnzufvbv3wq9a9n.txt)、[S03](sources/ar4fq2gbqxcz5ivn.txt)则概括要求文本可编辑、不栅格化。原文没有列出例外完整名单、审批方法或允许比例。**工程建议**：默认全部做原生可编辑文字；必须使用例外时单独标出用途与依据，不扩大到日期、地点、正文、价格等一般用户信息。

字体范围的原文也不完全一致：[原创 S02](sources/cnnzufvbv3wq9a9n.txt)写允许“【GD】版权字体”全部字体，禁止无版权字体或 AI 生成的版权不明字体；[二创 S03](sources/ar4fq2gbqxcz5ivn.txt)写“仅支持右侧侧边栏下【稿定库】内的字体样式”。**工程建议**：保留实际使用字体名称、编辑器库位置和授权来源，并验证目标编辑器能编辑和还原；不能自行认定两个库名完全同义，也不能将系统已安装字体等同于可商用字体。

### 5.3 智能拉伸

**平台教程**（[S05](sources/nq8p150hfxrzpoi5.txt)）：文字与规则底框组合可选智能拉伸；符合条件的非矢量内容底框建议启用。底框与文本打组，文本蓝框在底框内，文本与底框角度一致；PSD 导入前二者保持平行，导入后再旋转。异形底框换行变形可调整切割线，避开尖角、小元素。多文本/元素先各自实现智能拉伸再整体成组，原文附前提“所需元素之间不可重叠”。

**工程建议**：用长短不同的实际文案、换行和移动测试，检查底框方向及间距；不要把教程的可用条件泛化成任意复杂装饰都可自动拉伸。

### 5.4 PSD 是输入方式，解析成功后仍需检查

**平台说明**（[S02](sources/cnnzufvbv3wq9a9n.txt)）：会员可按图层整理规范上传 PSD 解析成模板；直接上传而没有解析的 PSD 会是一张图片，用户用不了也不能发布。非会员用 PS 制作，可拆出元素逐一上传编辑器制作。该文链接到的“图层整理规范”细则不在本次 12 篇分析范围内，本文不补造 PSD 命名、色彩模式、最大层数或特效白名单。

**工程建议**：核验解析后的背景、主体、投影、文字与编组，而非只核验扩展名；导入后检查字体替代、特效还原、遮挡顺序与移动表现。上述为落地建议，不代表本次已做编辑器实测。

## 6. 原创、二创与同质化的界定

| 情形 | 平台定义/态度 | 来源 |
| --- | --- | --- |
| 纯原创 | 无参考素材或他人作品，照片、排版、配色、插画、元素等独立完成 | [S02](sources/cnnzufvbv3wq9a9n.txt)、[S04](sources/nbs5bdp79cg2lt2w.txt) |
| 临摹照片并抽象化 | 列为原创案例情形，加入抽象创作呈不同风格 | 同上；本文未看案例图片，不能给出变化程度的视觉判例 |
| 借鉴并大幅改动 | 相似度低，可看作两个不同作品；借鉴点包括形状、姿势角度、风格、配色、版式、氛围 | 同上；没有相似度百分比，不能据此推导原照片/素材版权已消失 |
| 二创 | 从稿定站内已有模板出发，场景延伸、元素替换、尺寸延展、版式重构，形成不同主题/用途/场景/渠道的新作品；核心看相似度与关联性 | [S03](sources/ar4fq2gbqxcz5ivn.txt) |
| 渠道/尺寸延展 | 需排版调整，禁止仅改尺寸；例如海报转公众号首图 | [S03](sources/ar4fq2gbqxcz5ivn.txt)、[S04](sources/nbs5bdp79cg2lt2w.txt) |
| 用途/主题延展 | 如祝福转营销或放假公告、个人喜报转团队榜单；换主题必须调整画面，禁止仅改文案 | 同上 |
| 文案模块复用 | 可复用画面主文案、营销利益点、小红书标题；细小装饰文案不算，仅复制官方节气标题或地址电话模块不算 | 同上；“不算”是在该复用延展方向的语境，不能据此判断版权归属 |
| 抄袭/AI 洗稿 | 复制盗用，或极小表面改动仍明显相似；AI 洗稿不能规避 | [S02](sources/cnnzufvbv3wq9a9n.txt)、[S04](sources/nbs5bdp79cg2lt2w.txt) |
| 同一作者低价值刷量 | 同主视觉、相似场景/排版，批量换字换色；站内模板/元素拼接却无新场景和价值 | [S04](sources/nbs5bdp79cg2lt2w.txt) |

[S04](sources/nbs5bdp79cg2lt2w.txt)用“无延伸、无场景、无创意、无价值”概括同质化反例，并将配色、文案、风格、翻转角度、数量与细节微调列为可能仍属高相似的小改动。违规即使误审核通过，也可能追回奖励并在月度核算剔除。

**含糊/冲突**：S04 的概述把“尺寸调整、色调调整”列入二创手段，但具体条款和 S03 明确禁止仅改尺寸、文案、配色。应将这些视为可能参与实质创作的手段，不能独立作为合格二创依据。原文未给“大幅”“高度相似”“短时间大量”的量化阈值。

**工程建议**：记录参考来源与创作起点；把“站内模板衍生”与“从零设计中采用合法素材”分开说明；以场景、信息结构、构图、素材、视觉表达是否产生新价值做比较，不凭更换 AI 工具或换色声称原创。S02 还明确说定义示例不作为站内投稿视觉/排版参考，不能把其示例直接当设计母稿。

### 7.3 尺寸原文易错点与待核验项

这些问题来自[尺寸 source 文本](sources/fgkyq8l9mb8ax5a0.txt)；对部分印刷行已对照[同源 JSON 的 tables](sources/fgkyq8l9mb8ax5a0.json)，但没有访问其链接的物料细则。

- **竖版证书疑似笔误**：原文“证书/奖状-竖板版”模板为 **216×191mm**，并非本文常识推算的另一尺寸。保留原值，不能自动改成 216×291mm，制作前须核验创建画布或细则。
- **DM单并非标准 A4 数值**：原文成品 **210×285mm**，模板216×291mm；不能因为常见 A4 为210×297mm而替换。本表“节目单/年历卡”另列210×297mm，属于不同条目。
- **出血不全是3mm**：展板/文化墙原文是 **20cm**，最小字10cm、二维码42cm，单位明显不同。数值较大也不能不说明就改成20mm。
- **模板/成品不能互换**：多数成对列出的3mm出血物料两边合计差6mm；双面红包则模板195×221mm、成品88×165mm，不能套用简单减6mm公式，原文未提供展开刀模解释。
- **“横/竖”名称不能代替实际画布数值**：直播横版、竖版贴片都写1080×1080；可能描述贴片内容方向，但原文没有解释，本文不定论。
- **合并单元格易误读**：纯文本连续排列不等于每行都重列完整字段；电商主图、直播抖音等不要凭邻行补出新要求。自动结构化时需保留原表行/合并关系，不把缺值当作0或任意默认值。
- **文章长图的多画板语义待核验**：原表备注写“文章长图需要切成多画板，≥5个画板”，并列宽800、长度＞2000；它没有明确长度条件是总长还是每画板。另[S03](sources/ar4fq2gbqxcz5ivn.txt)说本次二创活动只参加平面编辑器，文章长图/详情页等长图编辑器暂不参加。尺寸被列出，不等于该活动允许通过长图编辑器投稿。
- **点评五连图存在不等式与组合尺寸歧义**：原文尺寸4000×600px，备注“每张3000x2250px≤X≥400x300px；长宽比例4:3”。不等式不能表达正常上下限，4000×600与每张4:3还涉及组合/单张关系。不得自动改写成“400×300至3000×2250”并标为确认标准。
- **重复条目细节不同**：应援“小卡-正反”60×96mm列300dpi CMYK、15pt、3mm出血；另“应援小卡”相同尺寸只列300dpi，其余空缺。空缺不等于取消前一条的要求，也不能跨条目无说明继承。
- **数量要求属于物料规范的一部分**：拍照KT板/手举牌6个为一个作品，线下打印KT板立牌1个作品；PPT 16:9条目写≥7页、投稿需单数页。不要把这些误当成尺寸或字号，也不要无依据扩展到所有物料。
- **单位不可统一抹平**：屏幕字号多为px，印刷多为pt，展板为cm，PPT为“号”；印刷cm/mm创建单位、DPI、像素尺寸是不同字段。原文“－”“/”或空白表示未明确，不等于无任何品质要求。

**工程建议**：尺寸登记同时保存物料名、原文数值、单位、模板/成品、DPI、字号、二维码、出血、画板/页数与来源。疑点做阻断提示而非自动纠错；当创建画布推荐与文档不同，记录实际值和依据，不覆盖采集原文。

## 8. GIF：动效不能牺牲可编辑性

**平台教程**（[S07](sources/ovuaxrhfisy9veew.txt)）：

- 文字和二维码一般不可做动效，因为以GIF存在后用户无法编辑、替换。
- PS帧动画时间不能设0.00，循环选择永久；帧数不超过20，时长不超过5s。
- 文件尽量不超过2M，海报不超过5M；另提醒下载后超过20M会裂图，超过10M有概率裂图，上传尽量控制2M以内。这些是不同情境的建议/风险值，不能合并成“20M以内即合格”。
- 暂只支持从编辑器点击发布；从“我的空间”发布预览可能为静态。
- 避免大面积渐变、杂点、噪点、叠加纹理，以减少文件体积与不自然过渡；透明GIF设置“杂边：无”。
- 透明、发光、半透明色块、原本不圆滑的边缘不适合透明GIF，可能出现消失、锯齿、杂边；原文建议相关效果带背景导出，渐变贴片可用PNG静态或编辑器图形还原。
- GIF背景单独导出后导入编辑器并设为背景。

**表述边界**：原文“GIF格式无法导出渐变”是教程绝对措辞，本文不将其当作GIF格式的普适技术定理；可确认的是该教程反对相关效果直接做透明GIF并提醒体积/过渡质量问题。

**工程建议**：把动效装饰/背景与需换字、换码的信息分离；分别验收循环、时长、文件大小、透明边缘及编辑器发布预览。原教程的“带背景导出”不能据此取消主体与背景的通用分层要求，具体合成方式仍需满足可替换目标。

## 10. 可用于制作/验收的执行清单（工程建议）

本节是依据上述原文组织的检查流程，**不是平台新增条款，也不代表已经完成这些检查**。

1. 写明实际行业、受众、渠道与用途，确认渠道允许的营销强度、LOGO和二维码范围。
2. 选择物料类型，确认创建画布推荐值；分别记录单位、尺寸、DPI、字号、出血、页数，疑点保留原值待核验。
3. 先确定阅读顺序和核心价值，再设计构图、字重字号、元素比例与配色；同时看缩略图和实际使用尺寸。
4. 检查场景文案完整准确、素材语义匹配、造型材质无误、风格协调，避免纯装饰替代用途。
5. 整理可编辑文本、可还原特效与合规字体；只有确有依据的专项主标题才考虑例外。
6. 按独立使用对象拆层，保留完整主体、干净背景与合理投影；按关系编组，适用时设置并测试智能拉伸。
7. PSD解析后实际核对结构和字体；GIF独立检查动效与文件约束；不能用文件存在代替效果判断。
8. 比较参考与站内原模板的场景、信息结构、排版、构图和素材变化，识别微调、批量同质化和AI洗稿。
9. 真实查看最终合成、隐藏/移动结果与导出效果，并记录观察。若只读过文字或看过缩略图，保留“未实看/未核验”，不得记作视觉通过。
