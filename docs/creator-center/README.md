## 对玩法的核心判断

### 先做真实用户需要的模板，再追求视觉和下载

[新手指南](https://gdce.yuque.com/gksiz6/bp2afo/vbnipc9zzf5wxkxz)、[行业场景](https://gdce.yuque.com/gksiz6/bp2afo/rc3gl6l7wof9cbdx)及[质量标准](https://gdce.yuque.com/gksiz6/bp2afo/fr75o0cutbee4r54)共同强调：明确行业、目标人群、用途、渠道与物料。上线基础要求与“优质”是两层；精美画面不能弥补信息不全、场景不对、无法编辑或版权不清。

选题应结合高需求、低满足度、低供给和真实场景，不仅看热点热度。小红书、公众号、直播间和线下印刷各有不同信息任务，不能一张图只改尺寸就投稿所有渠道。

### 美观差距主要需要设计与渲染共同修正

平台质量维度包括清晰、准确、统一风格、元素精准、合理版式、协调配色、平台审美和差异化。实际正反例显示：共同对齐、自然换行、合理分组与有限强调比“所有信息放大标红”有效；调色应把背景、文字、容器和装饰作为整体。

对当前插件，建议先补齐字距、行距、字体、对齐等参数在预览、PSD和稿定导入后的传递一致性，再增加低成本版式/配色草案与独立审稿。细节见[插件方案](05-插件改进方案.md)及[看图记录](06-关键配图视觉观察.md)。

### 分层以用户好改为目标，可以用skill组织

[编辑器教程](https://gdce.yuque.com/gksiz6/bp2afo/nq8p150hfxrzpoi5)要求独立完整的主体、干净背景、可编辑文字与合理编组；[避坑案例](https://gdce.yuque.com/gksiz6/bp2afo/td9amgo07k6gs6la)明确反对背景残留主体、多余图层和过大选框。

skill可组织语义分析、文字/形状重建、抠图修复、PSD合成与验收，复杂像素分割和遮挡补全仍需图像工具。建议优先“按层创作”：本地原生排版、独立背景/人物/装饰，减少整图生成后再次付费拆层；重型整图分层保留为补充路线。替代工具未安装或实测，不承诺免费无额度或质量等同。

### 话题有正式动态入口，固定五项需要贯通改造

[创作话题教程](https://gdce.yuque.com/gksiz6/bp2afo/ad6qnt5gu9gekpmv)实际链接到 [创作者中心灵感页](https://creator.huaban.com/inspiration)。语雀教程不是完整话题数据源。后续应检查实际来源中的推荐/活动、分页和状态，UI、工具、总控同时支持动态ID/URL，不只修改界面数组。

[话题专项](https://gdce.yuque.com/gksiz6/bp2afo/lulydfqo78dyqf6x)规定一稿只参加一次活动，多个活动以最后选定者为准；不同话题需独立任务。

### 收益分三类，最高值不当保底

截至本次11月快照：

| 类别 | 明确规则 | 重要条件 |
| --- | --- | --- |
| 下载分成 | 原创上线＜30天：1元×物料系数×下载UV；≥30天：0.5元×系数×UV；二创再×0.5 | 通过审核上线、真实下载；周一统计时决定是否满30天；素材共享分成等最终实得另核 |
| 活动现金奖 | 官方话题评选30—500元/作品；自建话题入围30—200元/作品 | 必须入围/获评，不是每稿30元保底 |
| 基础稿豆 | 审核上线10豆/作品；首次额外20豆 | 稿豆不是现金，违规下架可扣回 |

物料系数0.3/0.5/1/2/3，“最高3元/下载”仅对应相应条件。245稿豆可兑换1个月个人模板会员，资格、有效期、兑换频率需核实际入口。11月现金发放满30天与FAQ最低15元是不同条件；不能只达到15元就承诺马上提现。详见[完整收益分析](03-投稿版权与收益规则.md)。

### 原创路径、版权状态、审核状态分别记录

[原创/二创路径](https://gdce.yuque.com/gksiz6/bp2afo/okrohsuzflrstvbs)按从零创作或模板延展判断；自己的套图共用主视觉也有二创路径。原稿小修改走原作品“重新编辑”，不删除重发。

[版权认证](https://gdce.yuque.com/gksiz6/bp2afo/mwc8r0w7bvge6gkg)的“原创”则指完成认证且无非原创素材，是另一个维度。AI生成不自动豁免第三方IP/授权问题。证明材料要有真实过程，不能拿成品或一段声明替代。外部AI后端接入后，来源与证据也须一起改造。

投稿成功表示进入队列，审核中不是上线。作品审核通过也不能替代版权材料核验，更不能承诺后续永不下架。

## 使用与更新原则

1. 后续制作先读本入口，再按任务读相关专题；所有平台事实回到具体来源。每次生产仍核对当期话题、活动期、实时规范和实际界面。
2. 旧9月奖励、历史获奖公示、当日热词只能作为历史研究。保留日期与原值，疑似笔误、冲突或工具能力未经测试的地方明确标注。
3. 平台原文、整理归纳、工程建议和实测观察分别记录。已有流程文件是工程执行规范，本知识库不自动覆盖其安全恢复和真实验收要求。
4. 本目录含研究素材和原始公开快照，**不纳入插件runtime打包**，也不将参考图直接用作生产素材。

采集辅助脚本为本次会话研究工具，浏览器空间/目录参数属于本地配置；下一次刷新需要新建或明确复用实际TaskSpace，不能复制本次空间编号操作。脚本未调用生成或发布服务。
