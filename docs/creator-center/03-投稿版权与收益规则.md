# 投稿、版权与收益规则

> 整理日期：2026-11-06。核心分析为本章列出的11个已采集源页，并补充版权材料、原创扶持、活动细则和话题规则4页；依据正文及 JSON 的 `tables`、来源链接交叉核对，不代表已经核验所有外链、图片内文字或平台实时执行结果。本文“事实”指源页明确表述；公式示例为据此计算；“建议”单独列出。奖励会阶段性调整，“长期”不等于金额和条件永久不变。

## 1. 先分清五种状态与三类收益

**事实：**“点击发布后在【我的—发布】中出现”表示投稿成功、进入审核队列，不表示审核上线。普通审核说明同时写“3个工作日内”和“2—3个工作日”；审核中作品其他用户不可查看，浏览、下载数据为0。通过审核上线后，才进入相应奖励与下载分成的条件范围。作品下方浏览、下载展示截止昨日数据，刚发布或修改后建议隔一天再查；文中也称审核状态实时更新，不应把数据延迟与审核承诺混为一谈。[S10]

可按“编辑完成 → 发布入队 → 审核通过上线 → 被用户下载 → 结算、满足提现条件并提现”记录进度。版权认证是另外一条需要核实的状态，不能用投稿成功或审核通过代替。[S10][S11]

| 收益种类 | 明确条件与当前细则 | 不能据此承诺的事项 |
| --- | --- | --- |
| 下载分成 | 审核上线且被用户下载；金额取决于原创/二创、物料系数、上线时长和下载UV。[S2] | 不能把“最高3元/用户下载”理解为所有下载均3元，也不能把浏览量当下载UV。 |
| 创意活动现金奖 | 官方话题按活动评选，30—500元/作品；自建非官方话题须评选入围，30—200元/作品。[S4] | 审核上线不保证获奖；30元不是每份投稿的保底。 |
| 基础稿豆 | 审核通过上线10豆/作品；首次发布额外20豆；专页写“9月28日起”，未在该处明确年份。[S5] | 投稿入队不等于获豆；稿豆不等于现金收入。 |

11月总览允许同一作品叠加不同奖励，但仍须分别满足条件。总览示例提及“基础奖励（稿豆+现金）”，奖励FAQ提及“上线奖励”及月初发放，而基础奖励细则仅明确稿豆数量；本次材料不足以确认普惠现金上线奖的金额和资格，不能自行补出现金保底。[S1][S5][S7]

## 2. 原创、二创的定义与操作路径

### 2.1 判断看是否延展作品，素材来源另行判断

**事实：**原创是独立完成创意构思、版式结构、视觉设计及核心内容，未以平台其他作品为基础。二创是以平台已有作品为基础，经指定“延展/二创”入口继续编辑形成的作品。使用平台或他人素材本身不是二创的唯一判断依据；源页强调作品画面相似度、关联性及是否存在延展模板行为。[S3]

这意味着“作品是否原创”和“各素材是否本人原创、是否有授权”是两套判断：原创构图中可能包含非本人素材；自己的套图延展也可能属于二创。平台仍支持有价值的二创，但要求真实使用场景及与原画面有较大差异；同质化延展可能被下架和取消奖励。[S3][S10][S7]

### 2.2 对应的正确路径

| 情况 | 源页明确路径或要求 |
| --- | --- |
| 新原创 | 【创作】→新增画布/打开本地PSD→进入编辑创作。[S3] |
| 调整原有原创 | 原作品【重新编辑】后发布；不要创建副本，源页明确提醒会影响分成。[S3] |
| 延展他人作品 | 打开要延展的作品→进入编辑器→延展创作。[S3] |
| 延展自己作品 | 【我的】→发布管理→选原作品→【创建副本】→编辑器继续延展。[S3] |
| 已在线下完成PSD二创 | 先按二创路径创建副本，再在对应编辑器导入延展好的PSD；本地导入不会豁免二创路径要求。[S3] |
| 共用主视觉的倒计时、节日祝福/放假通知套图 | 先上传一张，后续按“延展自己的作品”操作。[S3] |

### 2.3 生效、追溯及申诉

**事实：**2026-09-28及之后提交或上线的作品，须按指定原创/二创路径操作，否则视为违规。此前已上线历史作品，未按规范二创路径操作不计入违规；这不等于取消其他版权、作弊或质量规则。禁止删除历史作品重新发布，批量删除重发会被视为违规。[S3]

违规作品可被取消所有相关收益，包括未发放收益、下载分成、活动奖励；已发放收益可从后续收益扣回。反复违规、恶意规避或严重情形可能限制投稿、取消未发放收益、冻结收益或封禁。平台通过站内信或运营说明作品、原因和处理结果；可通过该页所链“违规申诉表”申诉，通过后恢复符合条件收益。源文提及逾期但本次正文未写明具体申诉期限，应以通知确认，不推定天数。[S3]

## 3. 投稿资格、审核与后续维护

**事实：**参与共创不要求一定购买会员。会员可使用PSD解析；非会员可逐个上传元素、组合画面投稿。FAQ称非会员导入PSD会被识别成一张图片而非模板，无法直接发布。缺少发布按钮时检查个人版身份及平面编辑器；该FAQ原文还写“目前仅单屏编辑器可参与”，与多画板系数规则的关系需另行核实，不能据此宣布所有多画板投稿不可用。[S10][S6]

审核不通过时可进入作品查看理由，小问题通常有修改意见，整体质量不符时可能不显示理由；可重新编辑后提交。源页还提供“未精选作品反馈表”，称复核结果2—3个工作日。不要为修复原创作品另建副本，避免触发二创路径和分成变化。[S10][S3]

发布管理内删除内容即下架，后续不再产生下载分成；空间不足时FAQ建议清理发布管理以外的内容。上线后仍可能因版权、投诉、抄袭、与站内模板相似度过高而下架；上线不是后续永远有效的保证。[S10]

预览裂图常见原因是图层超过20MB；GIF预览图不能超过20MB，动态作品暂只支持编辑器内发布，不支持从“我的空间”发布。这里记录FAQ技术说明，不将“常见原因”扩大为唯一原因。[S10]

## 4. 原创素材认证、AI标注与素材授权

### 4.1 入口、范围与状态

**事实：**发布成功后可出现认证窗口；后续调整入口为【我的】→【发布】→【版权认证】。未认证素材或他人非原创素材的风险提示可能出现在编辑器右上角，并同步给用户，影响使用和下载意愿。认证有助于素材来源清晰和曝光，但不是对下载量或收益的保证。[S11]

支持编辑器内上传、本地拖动上传素材；PSD解析成模板后，须在编辑器右键将元素保存到“我的空间”，再发布完成认证。专页明确“PSD上传解析成模板直接认证”暂不支持，花瓣下载素材也不支持按素材编号识别认证。侧边栏素材由系统自动认证。认证范围写“6月3日之后发布作品”，此前作品可重新编辑、上传素材后发布完成认证；该处未明确年份，保留日期原文，不自行补年。[S11]

该页的平台状态定义为：完成版权认证且无非原创素材，标为“原创”；未完成认证，或虽认证但含非原创素材，标为“非原创”。这套**作品版权状态标签**不应直接替代第2节的原创/二创创作路径判定，源页没有说明两套标签一一等价。[S11][S3]

### 4.2 素材分类与声明

| 分类 | 专页定义 | 原表“是否需要声明” | 使用边界 |
| --- | --- | --- | --- |
| 稿定素材 | 从稿定下载的官方版权素材 | 否 | 系统自动认证不代表所有站外下载素材都是稿定官方素材。 |
| 原创素材 | 本人原创生成、拥有完整版权；被使用有分成 | 是 | 须如实分类，并提交声明材料。 |
| 原创AI素材 | 本人用AI生成、拥有完整版权；被使用有分成 | 是 | 含AI素材的作品还须勾选“含AI内容”。 |
| 非原创素材 | 他人/其他平台素材；被使用无分成，需自行核实版权归属 | 否 | “不需要声明”不等于获得授权，更不等于允许侵权使用。 |

以上均据认证页分类表；原创素材与原创AI素材均要求上传声明材料。[S11] 补读[《版权认证｜声明材料》](https://gdce.yuque.com/gksiz6/bp2afo/wrh7rgy4svyxi8kt)后可明确：[本地正文](sources/wrh7rgy4svyxi8kt.txt)要求实拍提供含设备、参数、时间地点等EXIF的原始照片；纸质手绘提供原稿照片，电子手绘提供分层等创作过程；GIF提供有创作痕迹的帧序列工具页面；素材提供有创作痕迹的图层工具页面。AI证明需创作记录截图，体现工具LOGO、完整关键描述、生成结果、模型等；有垫图须上传垫图。文字版自我声明、直接拿成品充当证明、乱填或提交不相符材料均为反例。材料必须真实完整有效，不能制作假平台截图。

**事实：**电影、动漫、游戏等第三方IP，即使经过临摹、改编或AI生成，也不属于本人原创；未经授权不可声明原创。无法确认授权的素材，源页建议谨慎使用或替换。“AI生成”本身不构成对第三方IP的授权，也不能自动满足“拥有完整版权”的分类条件。[S11]

### 4.3 原创素材被复用的收益

认证原创元素被别人用到新作品并产生下载时，专页称可获下载作品10%—50%的分成；分成说明也称“额外”收益。使用他人认证原创素材二创，作品下载收益须与素材创作者共享。[S11][S2]

**待核：**10%—50%的具体档位、触发条件、多个素材权利人之间如何分配及计费基数，11页中未给出可复算公式。路径FAQ称二创作者本人可拿“原分成×50%”，存在他人原创素材时平台按既定规则“额外给原创素材分成”；认证页称“共享”，但未完整说明是否从作者该部分再次扣减。不能自行把所有素材收益按50%扣除，也不能保证该比例总是额外叠加且不影响作者实得。[S3][S11][S2]

## 5. 下载分成：已确认公式与计算边界

### 5.1 公式

**事实：**分成页正文与 JSON 的第2张表（`tables[1]`）完整呈现下式，数字无需依赖图片猜测。设 `U` 为下载UV、`C` 为物料系数，则：[S2]

| 作品类型 | 上线＜30天 | 上线≥30天 |
| --- | --- | --- |
| 原创 | `1元 × C × U` | `0.5元 × C × U` |
| 二创 | `1元 × C × U × 0.5` | `0.5元 × C × U × 0.5` |

条件是作品通过审核上线、被平台用户下载。11月说明进一步规定每周一统计上周一至周日下载数据，**按该周一统计时作品是否上线满30天**决定档位。不能未经确认按每一次下载当时的作品年龄分别切档。[S2][S1]

“单创作者收益不封顶”描述账号总收益未设上限，不代表单个下载没有单价条件，也不是收益承诺。源页未完整说明下载UV的去重范围、同一用户跨日/跨作品计算、异常下载剔除过程及零头处理，实际结算须对照分成明细。[S2]

### 5.2 物料类型系数

以下分类由系数页正文与 JSON 表格逐项核对。[S6]

| 分类 | 系数 | 明确列出的物料 |
| --- | ---: | --- |
| 小图类 | 0.3 | 公众号首图、次图；主图图标、商品主图；明信片、名片。 |
| 配图类 | 0.5 | 公众号双封面；小红书封面、配图；视频/专辑/朋友圈/小说封面；文章配图、PPT单页、横板海报/banner等。 |
| 海报类 | 1 | 电商/印刷/竖版/全屏海报、展板、日签等；直播间贴片、背景、封面。 |
| 长图类 | 2 | 长图海报、易拉宝、印刷折页等；原文附“宽高比≥2.5倍即可选择多画布发布”。 |
| 多图类 | 3 | 多页PPT原文“需要单数页，＞7页、9页等”；文章长图“高度大于2000，≥5个画板”。 |
| 未命中分类 | 优先按1 | 原文为“优先按照物料系数1计算分成”，不写成所有例外绝对固定为1。 |

**待核：**长图的“宽高比≥2.5倍”是否指长边/短边、竖长图如何识别，文字未明确；PPT“＞7页、9页等”与单数页的关系不清楚，不能自行改为“至少7页”或“7页即可”；文章长图“高度”是否逐画板检查、单位和其他审核要求未完整说明。不应通过空白补页、机械拆画板推定获得高系数。[S6]

### 5.3 计算示例（推导，不是收益预测）

假设某作品恰有100个被结算的下载UV，且不考虑素材分配等未明确因素：

| 条件 | 据公式计算 |
| --- | ---: |
| 原创、小红书配图、＜30天、系数0.5 | 50元 |
| 原创、海报、＜30天、系数1 | 100元 |
| 二创、海报、＜30天、系数1 | 50元 |
| 原创、海报、≥30天、系数1 | 50元 |
| 原创、符合多图类、＜30天、系数3 | 300元 |
| 二创、符合多图类、≥30天、系数3 | 75元 |

因此标题“最高3元/用户下载”可由`1×3`推出，对应原创、＜30天、系数3；若原创且≥30天，同一系数对应1.5元/UV；二创且≥30天对应0.75元/UV。示例不代表这些作品能实际获得100UV，也不表示多图资格已被平台认定。[S2][S6]

## 6. 创意活动、基础稿豆与合伙人权益

### 6.1 创意活动现金奖

**事实：**创意活动页写“可叠加参与多个活动”，但[话题专项说明](https://gdce.yuque.com/gksiz6/bp2afo/lulydfqo78dyqf6x)明确“一个作品只会参与一次活动；选择多个活动话题，以最后选择者为准”。两页口径必须并列保留，不能承诺同一稿叠加多个活动奖；实际执行按专项限制记录最终活动。作品应符合主题、创作方向和投稿要求，具有明确场景、人群、原创度与创意，不能与平台内容雷同。审核上线后按活动规则评选，30—500元/作品；具体金额、名额、评选方式和时间以对应活动页为准。该范围是评选奖范围，不是通过审核即自动获得的现金奖。[S4]

自建话题允许多次投稿，但须在发布时添加自拟非官方话题，作品经评选入围获30—200元/作品。一般是当周投稿、下下周评选发放；节日话题在节后评选发放。不能把标题“每周评选”覆盖掉这条具体时间说明。[S4]

### 6.2 基础稿豆与兑换

**事实：**长期奖励页写审核上线10豆/作品、首次发布额外20豆，自动发放；因抄袭等下架会扣除账户内稿豆。首次奖励究竟以首次发布、首次审核上线还是历史账号资格为判断时点，页面未进一步细化。[S5]

稿豆可用于稿定AI、智能抠图等工具；不是现金提现单位。余额、有效期可在首页头像→管理与设置→账户一览→豆查看；专页写有效期自下发日起1年。[S8]

兑换会员须同时满足：账号正常、非封禁/异常/批量小号，已实名认证；近30天有正常UGC创作或发布行为，无刷量、搬运、洗稿、作弊记录。明确兑换项为**245稿豆兑换1个月个人版·模板会员**；入口为[创作者中心激励中心](https://creator.huaban.com/rewards)。会员权益与现金购买相同，但不赠送充值稿豆；不可转赠、折现、退豆、暂停，成功当日起算并自动叠加，兑换剩余稿豆保留。[S8]

专页写单账号**自然月最多1次**，并称单次仅可选1个SKU（1个月/3个月）；但没有在所读内容给出3个月兑换价格或明确其当前可选性。FAQ另写“30个自然日内兑换一次”，两者在跨月场景并不等价。不得据此承诺月末月初连续兑换，须以实际入口和运营确认。[S8][S7]

作弊获取稿豆可冻结兑换、清理违规豆；兑换后短期内（原文举例7天）注销、异常登录，平台有权撤销会员权益、追回消耗稿豆。“如7天”是举例，不能写成完整且唯一的追溯期限。规则第5问有“账号无通过违规手段……”的不顺畅原句，本章只记录其明确的冻结、清理后果，不据病句扩展额外资格要求。[S8]

### 6.3 创意合伙人（独立身份权益）

**事实：**合伙人计划署期2026-10-22，10月试运行不计考核，11月权益生效。首批根据数量、原创度、创意、质量、数据、活跃度综合评估，入选通过官方通知及专属社群邀请；名单动态更新，不是满足数量就自动入选。[S9]

| 权益/考核 | 明确内容 |
| --- | --- |
| 优先审核 | 工作日17:00前投稿当日完成审核；非工作日下一工作日优先安排。承诺的是审核，不是一定通过。 |

## 7. 结算、提现与违规扣回

**事实：**11月页写每周一统计上周下载；名单确认与奖励发放每周四，分成、活动奖励每周发放，节假日顺延。奖励FAQ则写每周四/周五，分成发放截止上周日的现金奖励；活动奖以活动文档为准，自建话题另有下下周或节后节奏。[S1][S7][S4]

现金在创作者激励中心发放；11月页写发放后满30天可提现，FAQ写达到15元最低门槛可提现。这两条是不同维度条件，不能只达到15元就承诺立即提现。合伙人有单独每月一次快速提现权益，但缺少完整适用细则。[S1][S7][S9]

违规后果须按具体条款记录，不能统一写成只取消当周奖励：

- 分成页：抄袭、侵权、与站内原模板相似度极高，取消当周分成。[S2]
- 活动与长期稿豆页：类似行为取消当周/当月收益，稿豆页另写下架扣豆。[S4][S5]
- 原创/二创路径页：违规作品所有相关收益可取消，已发放可从后续扣回；严重时限制投稿、冻结或封禁。[S3]
- 11月总览：内容违法、不合规范、刷量刷下载刷排名、冒用抄袭或未授权内容，可取消活动资格与所有奖励，包括已获得及未发放。[S1]
- 奖励FAQ：下架违规作品、取消对应奖励；异常账号套利可冻结关联收益并追扣；虚构下载可扣除违规期间收益、严重封号，并可依法追回及索赔。[S7]

## 9. 实务建议（本章推导，非平台新增规则）

1. 建立作品台账，分别记录原创/二创路径、关联原稿、content ID、发布和上线时间、物料类型、审核状态、版权分类、证明材料、结算UV、到账及可提现时间。这样能核对30天档位和实际分成差异。
2. 原创稿修改保留原稿走重新编辑；套图后续稿按自己作品延展路径；保存关键操作与版本证据。不要删除重发来重置作品年龄或规避二创识别。
3. 预算按能确认的物料系数和公式做情景测算；把下载量视为不确定输入，把活动奖列为评选机会，把稿豆与现金分开计量。先满足真实用途与质量，再选适合的物料形态。
4. 素材入稿即登记来源与授权。AI记录生成工具、任务与可用授权依据，含AI内容按要求标注；第三方IP不因换风格或AI再生成就自动可声明原创。
5. 每次活动先保留当期详情页和规则快照；领取或兑换前核对实际激励中心条件。对本章待核项向运营提出具体问题，并保存答复日期，避免将旧FAQ解释为当前确定承诺。
