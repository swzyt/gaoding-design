# 素材稿被拒复盘与重做计划（2026-11-18）

## 现象

素材稿 147 件里 **123 件被判 `QUALITY_REJECTED`**，通过率仅 16%。拒绝原因只有三类：

| 原因 | 数量 | 占比 |
| --- | --- | --- |
| 需元素抠图或者分层 | 54 | 44% |
| 质量不佳 | 68 | 55% |
| 需要分层 | 1 | 1% |

## 根因

平台对**元素类话题**要求交付「可独立使用、自由组合的单个元素」，规范原文例如：

- 特效系列光效素材：「创作可重复使用、灵活叠加组合的点光、光束、放射光等基础光效元素」
- 羊年新春活动有好戏：「素材尽量保持单体完整、背景简洁」
- 羊年祝福玩梗有一套：「元素可独立使用、自由组合」
- 年会艺术字玩出彩：「艺术字和元素可独立使用」

而插件此前**一律交付整张成品图**，且 163 份产物里 155 份完全没有透明通道。
平台收到的是一张拆不开的整版图 → 直接判「需元素抠图或者分层」。

反例佐证：唯一按整图交付还通过的「美妆个护上新背景」，规范要的确实是「展台背景」，整图才对。

## 修复（0.43.0）

1. `assetMode(spec)` 按规范原文判定 `element` / `scene`，建任务时冻结进 `unit.brief`：
   - 背景出现 ≥3 次且不提元素 → `scene`；
   - 命中「元素可独立使用 / 自由组合 / 单体完整 / 基础光效元素」→ `element`。
2. 素材 prompt 分流：元素模式强制单个元素、纯透明底、8% 透明边距、主体 30–75%、
   无文字/Logo/二维码/水印、边缘干净无白边；整图模式要求满版并留出产品位。
3. 生成阶段元素模式强制真透明（半透明/白底先自动抠图），记录 `minAlpha / borderMax / coverage`。
4. 投稿前检查新增 `element_alpha`、`element_border`、`element_coverage`，拦住整版图与贴边。
5. 0.45.0 追加质量与差异化提示：主体要有清晰轮廓与明暗对比、避免整体发灰、
   同话题多单元换不同视觉结构。
