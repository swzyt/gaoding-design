# 0.4：原生分层优先，默认脱离 Gaoding CLI

2026-11-06。已实现、回归和打包；不把本次开发验证当成真实投稿验收。

## 选定的方案

默认路线是：**实时选题 → 一个原创方向、2–4套本地原生版式 → 独立素材 → 看实际预览选优 → 原生文字PSD → 浏览器登记/导入/绑定 → 视觉和真实版权证据 → 按授权投稿**。

文字、背景色、容器、简单装饰直接本地生成。需要照片、人物、材质时，Agent使用已经可用的DSH图像插件、本地工具或原创素材，按独立背景/主体生成；重型抠图、遮挡补全及整图拆层只在确有需要时选用。默认不再先生成整张海报再付费做两套拆层。

选择它的原因：排版修改不需要重新付费生成；文字保持可编辑；背景和主体从创建时独立；可以替换图像供应商；来源和版权证据也能跟随实际工具变化。现有24GB Mac不适合作为默认运行重型CUDA分层模型的假设。ComfyUI/Qwen等可作为后续经过实测的后端，不用未经验证的模型代替本地基础流程。

图像任务通过持久Agent交接接入，不硬编码某个付费服务。当前DSH启用的插件中未发现独立生图插件，因此本轮没有声称外部生图服务已配置/已实测；纯文字和程序图形可完全本地运行，复杂图像需要现成或后续配置的真实图像能力。缺能力会停在明确交接门，不静默回退GD CLI。

| 外部图像 | 固定计划、token、实际provider/model/input/task或invocation、资源及证据哈希；透明度/路径/分类验证 |
| 素材登记 | 默认浏览器Agent交接，保存真实库ID、asset ID和重开截图；不再强制CLI查询/上传 |

| 交付 | 原始工具响应、截图、素材计划和来源清单进入材料包，不仅保留报告图 |
| 依赖 | 默认doctor不检查GD CLI；显式legacy doctor保留旧编码回归；原有CLI任务可恢复 |

浏览器登记是Agent按冻结请求操作当前界面、再经代码校验的交接，不是未经实测的私有上传API适配器。PSD导入、字体、绑定、隐藏恢复和投稿仍使用现有浏览器代码；生产时必须实看平台结果。

## 兼容和边界

- 新run默认 `native/agent`；旧run没有mode字段时保持原 `gd-cli/gd-cli`，不在恢复时改变路线。只有明确选择兼容后端才调用CLI，无自动付费回退。
- 只预览用 `preview/build`；`auto`仍会进入投稿阶段，必须有投稿授权。
- 原生文字暂不支持非零旋转、复杂文字非零逐字距、半透明文字色及未实现阴影/渐变/warp；拒绝优于导入后悄悄变样。字重使用明确字体，不能伪造。
- 本地PSD重读验证不等于稿定重新排版验证；实际字体可用性、版权、导入后构图需在生产门确认。
- 实时目录11题本次缺规范链接，仍显示但研究可能无法自动解析唯一入口；不拿其他题规范补洞。话题数和活动有效性随平台变化。
- 目前仍仅声明macOS，中文预览使用系统字体。外部图像服务费用按实际能力和额度，不承诺免费无限制或固定节省比例。
