# 变更记录

只记录对使用者有意义的变化。版本号见 `package.json`。

## 0.42.1（教程在面板内直接打开）

- 修「点使用教程没反应」：不再用 `window.open`（应用内可能被拦），改成面板内弹层，
  由 `GET /docs/USAGE?format=json` 取渲染好的 HTML 内嵌显示，弹层里另有「在新窗口打开」。
- 仓库新增 [docs/README.md](../docs/README.md) 文档索引，教程同时存在于 `docs/USAGE.md` 与包内 `USAGE.md`。

## 0.42.0（教程可直达）

- 面板右上角新增「使用教程」按钮，新窗口打开渲染好的教程（`GET /docs/USAGE`，自带样式、表格、代码块）。
- 仓库新增 `docs/USAGE.md`，与包内 `USAGE.md` 内容一致；单测会校验两份必须相同，避免漂移。
- 教程渲染器只支持文档用到的子集，原始 HTML 一律转义，危险链接丢弃。

## 0.41.x（使用教程 + 进入页面即环境自检）

- 新增 [USAGE.md](./USAGE.md)：从一次性准备、读自检、选话题、写 prompt、出图、创作、
  投稿与声明、批量与队列、结果查看，到故障速查与术语表；随包分发。


- 新增 `GET /preflight`：进入面板先检查数据目录、Python/Pillow、ego-browser、浏览器登录态、
  订阅出图凭据、GD CLI、插件版本；30 秒缓存，可 `?refresh=1` 强制重探。
- 面板顶部显示自检结论：正常一行绿字；有缺失列「原因 → 修复建议」；
  **必需依赖缺失（数据目录/Python/ego-browser）时禁用创作与投稿**，避免点了没反应。
- 自检新增「DSH 图像插件（dsh-image-gen）是否安装」一项：未装时提示去 Plugin Manager 安装，
  否则订阅登录与出图界面都没有入口（只能走 GD CLI 稿豆）。
- 自检只读：不安装依赖、不改配置、不触发付费动作。

## 0.40.x（文档与发布整理）

- 重写插件 README：面板四个标签页、三种出图后端、质量门槛、声明口径、路由清单、故障排查。
- 测试移除硬编码机器路径，改为 `DSH_GAODING_DATA` / `DSH_GAODING_PYTHON` 或 HOME 相对路径；缺少本机夹具时跳过而不是失败。
- 打包校验继续扫描机器路径与账号 ID。

## 0.39.x（全自动真正闭环）

- **插件自己出图**：复用 DSH 图像插件已登录的 ChatGPT 订阅凭据（`CODEX_OAUTH_1`，另兼容 `CHATGPT_OAUTH_1` / `OPENAI_OAUTH_1`），直接调订阅出图接口，全自动不再等人，0 稿豆。
- 生成后本地缩放并按需**白底自动抠透明**；透明底判定改为「最小 alpha ≤16 才算真透明」，半透明边缘不再冒充贴纸。
- **素材断点复用**：已生成且尺寸正确的素材直接复用，中断/重装后继续跑不再重复消耗额度；每张落地即写回执。
- 中断可续跑：既有没有失败记录的创作中断，从「拒绝重生成」改为 `resume:` 继续。
- 创作状态也纳入运行态持久化，重启后能看出哪些被中断。
- 发布弹窗没出现时自动重开（最多 3 轮）；弹窗内点击遇到元素句柄失效时重新快照再点。
- 新增 `POST /image/test` 出图自检路由。

## 0.38.x（状态语义与面板可读性）

- 创作列表的单元/任务状态改为从真实产物推导：已投稿 > 投稿中 > 已创作待投稿 > 创作中 > 等待素材 > 失败 > 待创作 > 排队中；已全部投稿的任务显示「已完成」。
- 等待素材不再显示成「创作失败」；顶部状态单独为「等待出图素材」，并列出待出图素材 ID。
- 确认生成面板的稿豆提示跟随所选后端，选 DSH 出图时不再显示稿豆单价与余额。
- prompt 区域默认收起，只显示两行摘要 + 字数，按单元展开编辑。

## 0.37.x（全自动链路修复）

- 出图后端随任务持久化，重试不再退回 `gd-cli`（此前会白花稿豆）。
- 自动链路接受 `image-gen` 后端；素材未就绪时状态为 `waiting-assets` 而不是 `failed`。
- 图像装饰不再被 4% 面积门误杀；纯色装饰层直接丢弃。
- 新增 `POST /publish/resolve-uncertain`：没有 contentId 的不确定提交也能对账（平台无新作品则归档允许重投）。
- 修复 `lines is not defined`（弹窗重试改造时的回归）。

## 0.36.x（批量与队列）

- 批量投稿、批量取消；未开始的任务可取消（`cancelled`），已开始的只能等它跑完。
- **发布队列**：串行执行、状态原子落盘、失败隔离、可停止可续跑、重复启动不会重复执行。
- 运行时状态持久化：投稿/链路/创作状态重启可恢复，被打断的标记 `interrupted`。
- 素材稿支持「DSH 出图」后端。

## 0.35.x（质量门）

- 版式质量门：字号下限 24px、层级 ≤4 档、主标题 ≥ 正文 1.6 倍、文字对比度 3:1 / 4.5:1、背景铺满、主体 ≤35%、除容器外不得压字、图层 ≤16。
- 纯色装饰层丢弃（此前常被误看成渲染错误）。
- 已投稿页：状态徽标点击筛选、按时间/浏览/下载排序、导出 CSV、跳转平台详情。

## 0.34.x（模板链路跑通）

- 模板声明改为「含 AI 图层的整稿声明原创 AI 素材」，去掉脆弱的逐层像素匹配（平台会重编码预览图、并按内容去重候选）。
- 撤销重发支持显式 `force`，并在重发时**强制重新导入设计**——复用同一设计时平台不再提供「去完善」声明入口。
- 修复单分类场景未执行「移动至」导致候选留在未分类。

## 0.29–0.33（图像层与声明）

- 模板从「纯色块」升级为真实图像层：素材交接协议（请求/回执/哈希/alpha/尺寸校验），缺素材明确报 `ASSETS_WAITING`，不偷偷退回纯色块。
- 混合来源声明：程序图形与 AI 图分层归类、各自上传证据。
- 声明候选匹配从字节哈希改为感知指纹（16×16 平均哈希 + 主色 + 宽高比），并处理跨域 canvas 污染（fetch blob + `createImageBitmap`）。
- 投稿前检查、发布管理多页读取、状态判定口径统一。
